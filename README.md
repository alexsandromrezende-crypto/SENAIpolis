# SENAIpolis 6.0 — Cidade Interativa com Obstáculos Dinâmicos

Nova versão do jogo educacional em HTML, CSS e JavaScript.

## Novidades desta versão

- cidade mais povoada, com mais prédios, comércio e equipamentos urbanos;
- 20 obstáculos dinâmicos no trajeto (13 novos) até as missões (ônibus, entrega, ciclistas, motoboy, pedestre etc.);
- sistema de checkpoint: quando o carrinho é tocado por um obstáculo, volta ao último ponto seguro;
- zoom no mapa e exploração livre da cidade;
- 5 missões sequenciais com 3 desafios cada (15 desafios);
- perguntas e enigmas sorteados a cada nova campanha;
- cadastro, login, foto opcional e relatório em PDF.

## Como usar

1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. Crie um cadastro ou entre com um perfil já salvo no próprio navegador.
4. Explore a cidade com as setas ou WASD.
5. Pressione `E` perto da missão liberada.

## Observação

Os dados desta versão continuam sendo salvos localmente no navegador (`localStorage`).
